# Piano samples

The app's piano voice uses samples from the **Salamander Grand Piano V3** by Alexander Holm,
licensed under [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).

- Source recording: <https://archive.org/details/SalamanderGrandPianoV3>
- These MP3s are the Tone.js project's encoding of that set (<https://tonejs.github.io/audio/salamander/>),
  downloaded 2026-10-07 unchanged: one note every minor third from C2 to C6 (`Ds` = D♯, `Fs` = F♯).

Notes between samples are pitched from the nearest one (at most 1.5 semitones). See
`../pianoSamples.ts` and `docs/decisions.md` (2026-10-07 "Piano voice").
